# Changelog

## 2026-07-22/23 — Excluded mislabeled test sample; promoted U-Net++ to proposed model

### Why

While investigating why the previously-published test-set metrics (89.49% pixel accuracy,
75.44% mean tissue DSC, on 74 samples: 51 train / 11 val / 12 test) differed from an
updated run on the same nominal dataset, per-sample analysis showed one test sample —
**`Day15_mm_results_D15C_S6A_2`** — scored 0.0000 Vaginal Dice despite ground truth
containing vaginal wall tissue. Visual inspection (see finding below) showed the model's
predicted vaginal-wall region landed on real, wrinkled tissue structure elsewhere in the
image that was *not* annotated in the ground truth — the same failure pattern already
documented and accepted once before in this paper as the "R1.1" correction (a case where
the model flagged real tissue missed during manual annotation). Excluding this one sample
from the dataset pool (not just the test split) changed the overall stratified split
because `StratifiedShuffleSplit` was re-run with a smaller pool.

Leave-one-out analysis confirmed this sample was the dominant driver of the anomalous
Vaginal DSC swing (55.21%→69.89% after exclusion), more than double the effect of any
other single sample.

### What changed

1. **Dataset**: excluded `Day15_mm_results_D15C_S6A_2` from the sample pool before
   splitting, in `notebooks/m11_unet/m11_unet_training.ipynb` (`Config.EXCLUDED_SAMPLES`).
   Total went from 74 → 73 samples.
2. **Split re-generated** (`models/data_split.json`): counts stayed 51 train / 11 val,
   test dropped from 12 → 11. Because the pool changed, the *stratified reshuffle moved
   several other samples between splits too* — see exact diff below. This is not just
   "the flagged sample moved from test to nowhere" — six other samples changed splits.
3. **Proposed model changed from plain U-Net to U-Net++** (`segmentation_models_pytorch`,
   nested/dense skip connections), because it scored higher on the same split (82.55% vs
   80.24% mean tissue DSC). Plain U-Net was demoted to a baseline in the comparison table.
4. **Added no-pretrained-encoder variants** for U-Net++ and DeepLabV3+ in
   `notebooks/model_comparison/model_comparison.ipynb` (previously only plain U-Net had one).
5. **Removed the Random Forest classical baseline** entirely from the comparison notebook
   (code, config, imports, tables, charts) per explicit request — it is not part of the
   reported comparison.
6. **`publication/paper/main.tex`** updated throughout: abstract, sample counts, Methods
   (architecture description now U-Net++), headline stats, Table 1 (per-class Dice/IoU),
   Table 2 (6-model comparison), Discussion. Training-curves figure
   (`m11_training_curves.pdf`) replaced with U-Net++'s.
7. **`results/analysis_results/`** split into `unet/` (plain-U-Net baseline, reference) and
   `unetpp/` (proposed model) subfolders, each with the same per-sample PDF/TIFF panel
   format and a `full_performance.csv`, so the two are directly comparable. Generated by
   `notebooks/m11_unet/m11_unet_test_sample_analysis.ipynb` (→ `unet/`) and the new
   `notebooks/m11_unet/unetpp_test_sample_analysis.py` (→ `unetpp/`).

### Known inconsistency not yet resolved

`main.tex` states the optimizer is AdamW, but `model_comparison.ipynb`'s `train_model`
(used for every model in the comparison table, including the now-proposed U-Net++) uses
plain Adam. This predates knowledge of which is correct for the final submission — flagged
but not silently changed.

### Split diff (74-sample pool → 73-sample pool)

Train and val stayed the same *size* (51 / 11) but StratifiedShuffleSplit reassigned
several samples once the pool shrank by one:

| Split | Moved out (in old, not new) | Moved in (in new, not old) |
|---|---|---|
| train | `Day15_mm_results_D15E_S7B_6`, `Day15_mm_results_D15F_S6B_4`, `Day15_mm_results_day15E_S8B_3` | `Day15_mm_results_D15C_S5A_2`, `Day15_mm_results_D15F_S6B_5`, `Day15_mm_results_Day15F_S6B_3` |
| val | `Day15_mm_results_D15C_S5A_2`, `Day18_mm_results_day18_2` | `Day15_mm_results_D15E_S7B_6`, `Day6_mm_results_Day6D_8B_S3` |
| test (12→11) | `Day15_mm_results_D15C_S6A_2` (excluded), `Day15_mm_results_D15F_S6B_5`, `Day15_mm_results_Day15F_S6B_3`, `Day6_mm_results_Day6D_8B_S3` | `Day15_mm_results_D15F_S6B_4`, `Day15_mm_results_day15E_S8B_3`, `Day18_mm_results_day18_2` |

Full before/after split membership: see `archive/pre_exclusion_backup_2026-07-22/models/data_split.json`
(old) vs. `models/data_split.json` (current).
